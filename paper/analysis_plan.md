# Analysis plan

The unit is one UTC-midnight forecast for each of the two Ethereum Aave version series represented in the frozen Chaffard dataset. The graph IDs 111 and 1599 refer to global Aave V2 and V3, respectively. The mapping provides a version-level external covariate. A chain-version matching rule provides consistent labels while the source evidence supports only partial correspondence between the event series and outstanding borrowing reported by DefiLlama. The latter's Ethereum V3 adapter includes multiple pool providers, so the primary target is the tail of the source-reported USD liquidation volume. The volume divided by lagged Ethereum version borrowing is a sensitivity estimand with a broader normaliser. Both targets use the version-specific training 95th percentile.

The primary origin period is 1 March 2023 to 25 August 2025, with the upper bound excluded. Use observations strictly before the origin, an assumed seven-calendar-day graph reporting lag, and one calendar day of buffer between the last eligible training or development outcome and the next partition. Use expanding folds with disjoint tests from April to July 2024, August to December 2024, and January to 24 August 2025. Training estimates all cutoffs and normalisation. The first half of each development block selects neural stopping epochs. The second half fits probability calibration and alert thresholds. Test predictions use fixed settings.

1. Compare a market-augmented GRU against a direction-aware temporal weighted-aggregation model with the same history. This is the primary comparison for incremental network information. Report average precision and Brier score with paired blocked intervals.
2. Estimate the contribution of market series with a graph-only-input ablation that retains the local Aave variables. Compare against base rates, a recent-liquidation ranking, regularised logistic regression, LightGBM, and a static-neighbour graph.
3. Compare a single neural member, the raw ensemble and calibration by ridge Platt scaling and isotonic regression. Rank ensemble disagreement against predictive entropy for selective prediction. Report the false-alert and review burden for the two alert policies, counting a review as distinct from an automated alert.
4. Repeat evaluation with random graph-edge thinning at 10, 30 and 50 percent, plus a one-day oracle delay, a seven-day extra graph delay, and a combined scenario. Compare independently seeded graph models trained with 30 percent thinning and oracle-delay augmentation against clean training. Keep calibration fixed under all test perturbations.
5. Report descriptive test slices around the documented August 2024 market turbulence and February 2025 Aave liquidation wave. Run secondary six-hour and seven-day targets at the same UTC-midnight origins and a 24-hour active-borrowing-normalised target. Interpret longer-horizon overlapping outcomes with the time-block procedure.
6. Estimate graph-weighted lagged spillover associations using only already observed outcomes and an unweighted other-version control. Treat this as a predictive association between two labelled versions, with the global graph providing a weight. No experiment in this study identifies causal contagion or protocol insolvency.

Design fixed after inspecting provider documentation and source schemas, before inspecting model performance. The code, configurations and provenance manifest define the executable specification.
